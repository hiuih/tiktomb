# TikTomb

A native macOS wrapper for [TikTok](https://www.tiktok.com) built with Electron. Real dock icon, real title bar, working camera/mic, native notifications — the real TikTok in an app that feels like it belongs on your Mac.

**Unofficial, independent project.** Not made by, affiliated with, or endorsed by TikTok/ByteDance. It's a thin native shell around TikTok's own website — every account, video, and DM is served by TikTok's real servers.

## Install

Download the latest `.dmg` from [Releases](../../releases), open it, and drag TikTomb to Applications. Unsigned build — first launch: right-click → Open.

## Build from source

```bash
npm install
npm run dist
```
